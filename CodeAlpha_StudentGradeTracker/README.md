# CodeAlpha Student Grade Tracker

A console-based Java application developed as part of the **CodeAlpha Java Programming Internship – Task 1**.

## Features

* Add multiple student records
* Store student names and grades
* View all student records
* Calculate average grade
* Find highest grade
* Find lowest grade
* Generate a summary report
* Validate student names and grades

## Technologies Used

* Java 21
* Java Collections (`ArrayList`)
* Object-Oriented Programming
* IntelliJ IDEA

## Project Structure

```text
CodeAlpha_StudentGradeTracker
└── src
    ├── Main.java
    ├── Student.java
    └── GradeManager.java
```

## How to Run

1. Open the project in IntelliJ IDEA.
2. Open `src/Main.java`.
3. Run the `Main` class.
4. Use the console menu to manage student grades.

## Task Requirements Covered

This project covers the main requirements of CodeAlpha Task 1:

* Managing student grades
* Calculating average, highest, and lowest grades
* Using an `ArrayList` to store student records
* Displaying a summary report
* Console-based implementation
