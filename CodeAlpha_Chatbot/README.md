# CodeAlpha Chatbot

A console-based Java chatbot application developed as part of the **CodeAlpha Java Programming Internship – Task 3**.

## Features

* Start a conversation through the console
* Respond to common greetings
* Answer basic predefined questions
* Handle simple user inputs
* Display a default response for unknown messages
* Exit the chatbot using a simple command

## Technologies Used

* Java 21
* Object-Oriented Programming
* String handling
* Conditional statements
* IntelliJ IDEA

## Project Structure

```text
CodeAlpha_Chatbot
└── src
    ├── Main.java
    └── Chatbot.java
```

## How to Run

1. Open the project in IntelliJ IDEA.
2. Open `src/Main.java`.
3. Run the `Main` class.
4. Enter messages in the console.
5. Interact with the chatbot using the available commands.
6. Use the exit command to close the chatbot.

## Task Requirements Covered

This project covers the main requirements of CodeAlpha Task 3:

* Creating a simple chatbot using Java
* Handling user input through the console
* Providing predefined responses
* Using conditional logic for different user inputs
* Creating an interactive console-based application
